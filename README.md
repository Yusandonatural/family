# おてつだい こづかい帳

子どもたちのお手伝いを記録して、1ヶ月ごとにお小遣いを計算するアプリです。

- `index.html` をブラウザで開くだけで使えます（インストール不要）
- カレンダーの日付を押して、その日にしたお手伝いを選びます
- 「みんな」タブでは全員の日ごとの金額、各こどものタブではその子のお手伝い内容を表示します
- 上のカードに今月のしきゅう額、下の「今月の明細」にお手伝いごとの回数と金額が出ます
- お手伝いの種類・金額・こどもは画面下から追加・変更・削除できます
- 金額を変更しても、すでに記録した日の金額は変わりません
- 記録はブラウザ（localStorage）に保存されます。「バックアップ」から JSON ファイルに書き出し・読み込みができます

# まいにち30ぷん（英語＆算数） `study/`

年少さん〜小学6年生向けの家庭学習アプリです。10分のレッスン1回クリアごとにゲームタイム10分（標準。子どもごとに10〜60分で変更可）。
公開URL：https://yusandonatural.github.io/family/study/

- 英語が中心（標準7割）＋算数。学年別に問題を自動生成、正解率で難しさを自動調整
- ⚔️ クエスト制：10問（年少〜年長は8問）で1クエスト。8割以上正解でその場でレベル+1、4割以下で−1。星（1〜3）とXPでプレイヤーレベルが上がる
- 🇬🇧 英語は中3まで：学年に中1〜中3を追加。英語は学年に関係なく 小1→…→小6→中1→中2→中3 の順に「段階」が進む（各段階 Lv1〜6、Lv6で8割正解すると次の段階へ。次の段階はLv3から、前の段階の復習も混ざる）。算数はその学年の内容まで（Lv1〜6、上の学年は出さない）。中学の文法（be動詞〜現在完了・受け身・関係代名詞・仮定法）、単語、英文の聞き取り・並べかえ（`study/js/jh.js`）。えいかいわロードは中学レベルが30ステップ（各学年10ステップ、文法の順に並ぶ）で全45ステップ。中学の文法156問・単語184語
- 📦 データの引き継ぎ：引き継ぎコード（コピー＆貼り付け）またはファイルで、別のアイコン・ブラウザ・端末の記録を移せる。今の記録は消さずに合体
- 🔁 一度正解した問題は二度と出さない。まちがえた問題だけクエストの最後に復習し、正解するまで「まちがいノート」から次の日以降も出る
- 飽きないように、同じ問題は10分間は出さない（まちがえた問題は10分後にもう一度）
- 🎯 目標：英語は「英語で会話ができる」をゴールにした15ステップの「えいかいわロード」（あいさつ → 気持ち → 名前 → 好きなもの → 数・年齢 → 何・何色 → お願い・誘い → できること → 時間と生活 → 場所・道案内 → 買い物 → 誕生日・季節 → 将来の夢 → したこと → 自己紹介スピーチ）。聞き取り・受け答え・穴うめ・並べかえ・声に出して言う練習（マイク判定）で進み、表現を全部2回ずつ正解すると次のステップへ。保護者が目標ステップ・期限、算数の重点単元と目標正解数を設定できる（教材データは `study/js/conversation.js`）
- スタンプカレンダー、連続日数、スター、メダルで毎日続けるしかけ
- はみがき・しゅくだい等のタイマー、iPad/Android の時計アプリのタイマー連携
- iPad 向けレイアウト、ホーム画面に追加して全画面・オフラインで使える
- 記録は端末（localStorage）に保存。保護者画面からバックアップ／復元
- ⭐ まなびポイント：べんきょうした時間 1分 = 10ポイント（30分 = 300ポイント）。ゲームタイムを使うと 1分 = 10ポイント減る。ポイントは 百人一首・日本史など ほかのアプリと共通（https://yusandonatural.github.io/idea-/kids/ ）

# えいかいわコース `eikaiwa/`

年少〜中学3年までの45ステップで、英語で会話ができるようになることを目指す英会話専用アプリです。
公開URL：https://yusandonatural.github.io/family/eikaiwa/

- さいしょに「だれが べんきょうする？」（まなびの いりぐち と同じ子ども）、はじめての子は学年を選ぶと ちょうどいいステップから始まる（年少→ステップ1、中1→16、中2→26、中3→36）
- ステップは まいにち30ぷん の「えいかいわロード」と同じ教材（`study/js/conversation.js`）。ようじ〜小学校15・中1 10・中2 10・中3 10
- 1レッスン10問：聞いて意味をえらぶ・日本語から英語をえらぶ・穴うめ・ならべかえ・受け答え・声に出して言う（マイク判定、使えないときは とばせる）。まちがえた問題はレッスンの最後にもう一度
- ひょうげん・やりとりを2回ずつ正解すると そのステップをクリアして次が開く。まえのステップの復習も毎回2問まざる
- 「かいわ れんしゅう」で先生の質問に返事をえらんで声に出す ロールプレイ
- べんきょう 1分 = 10ポイント（まなびポイント共通）。記録は端末（localStorage `eikaiwa:v1`）
