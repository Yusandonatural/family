# おてつだい こづかい帳

子どもたちのお手伝いを記録して、1ヶ月ごとにお小遣いを計算するアプリです。

- `index.html` をブラウザで開くだけで使えます（インストール不要）
- カレンダーの日付を押して、その日にしたお手伝いを選びます
- 「みんな」タブでは全員の日ごとの金額、各こどものタブではその子のお手伝い内容を表示します
- 上のカードに今月のしきゅう額、下の「今月の明細」にお手伝いごとの回数と金額が出ます
- お手伝いの種類・金額・こどもは画面下から追加・変更・削除できます
- 金額を変更しても、すでに記録した日の金額は変わりません
- 記録はブラウザ（localStorage）に保存されます。「バックアップ」から JSON ファイルに書き出し・読み込みができます

# まいにち30ぷん（英語＆算数） `study/`

年少さん〜小学6年生向けの家庭学習アプリです。10分のレッスン1回クリアごとにゲームタイム10分（標準。子どもごとに10〜60分で変更可）。
公開URL：https://yusandonatural.github.io/family/study/

- 英語が中心（標準7割）＋算数。学年別に問題を自動生成、正解率で難しさを自動調整
- ⚔️ クエスト制：10問（年少〜年長は8問）で1クエスト。8割以上正解でその場でレベル+1、4割以下で−1。星（1〜3）とXPでプレイヤーレベルが上がる。英語・算数のレベルは1〜15（はじめはLv4、Lv7〜は上の学年にチャレンジ、小6はLv6まで）
- 🔁 一度正解した問題は二度と出さない。まちがえた問題だけクエストの最後に復習し、正解するまで「まちがいノート」から次の日以降も出る
- 飽きないように、同じ問題は10分間は出さない（まちがえた問題は10分後にもう一度）
- 🎯 目標：英語は「英語で会話ができる」をゴールにした15ステップの「えいかいわロード」（あいさつ → 気持ち → 名前 → 好きなもの → 数・年齢 → 何・何色 → お願い・誘い → できること → 時間と生活 → 場所・道案内 → 買い物 → 誕生日・季節 → 将来の夢 → したこと → 自己紹介スピーチ）。聞き取り・受け答え・穴うめ・並べかえ・声に出して言う練習（マイク判定）で進み、表現を全部2回ずつ正解すると次のステップへ。保護者が目標ステップ・期限、算数の重点単元と目標正解数を設定できる（教材データは `study/js/conversation.js`）
- スタンプカレンダー、連続日数、スター、メダルで毎日続けるしかけ
- はみがき・しゅくだい等のタイマー、iPad/Android の時計アプリのタイマー連携
- iPad 向けレイアウト、ホーム画面に追加して全画面・オフラインで使える
- 記録は端末（localStorage）に保存。保護者画面からバックアップ／復元
