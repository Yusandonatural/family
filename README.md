# かぞくのアプリ

ホーム画面から 2 つのアプリを開ける家族用アプリです。`index.html` をブラウザで開くだけで使えます。

## まいにち30ぷん（`js/app.js` ほか）
英語と算数の学習アプリ。30分がんばるとゲームタイムがもらえます。記録は端末ごと（localStorage）に保存されます。

## おてつだい こづかい帳（`js/kozukai.js`, `css/kozukai.css`）
- カレンダーの日付を押して、その日にしたお手伝いを選びます
- 上のカードで「みんな」と各こどもを切り替え、今月の金額が一目で分かります
- 「明細」にお手伝いごとの回数と金額、月末のしきゅう額が出ます
- お手伝いの種類・金額・こどもは画面下から追加・変更・削除できます（金額を変えても記録済みの日はそのまま）
- claude.ai のアーティファクトとして開くと、家族のスマホで記録を共有します。それ以外ではその端末に保存します
- 「バックアップ」から JSON ファイルに書き出し・読み込みができます

## きょうの うんせい（`js/uranai.js`）
星命録（極 家族版）の日運の計算（日干支の干合・支合・三合・冲・空亡）、動物占い、太陽星座を使い、生年月日から今日の運勢・ラッキーカラー・今週のいい日を出します。
こどもの画面ではその子の運勢、「おうちの人」では全員の一覧と誕生日の設定（おとなの追加も可）ができます。誕生日はこづかい帳の設定と一緒に共有されます。

## 最初の画面
名前を選ぶと、その人のメニューから3つのアプリを開けます。

見た目は まいにち30ぷん の `css/style.css` を共通で使っています。
